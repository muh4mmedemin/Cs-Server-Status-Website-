## Gereksinimler

- Cluster'da çalışan bir hesap
- Disk alanı: ör. ~2 GB (`goinfre` veya `sgoinfre`)
- Gerekenler: ör. `git`, `curl`

> [!NOTE]
> Kurulumdan önce bilinmesi gereken bir şey varsa buraya yazın.

## Kurulum

1. Depoyu indirin:

   ```bash
   $ git clone https://github.com/KULLANICI/PROJE.git
   $ cd PROJE
   ```

2. Kurulum betiğini çalıştırın:

   ```bash
   $ chmod +x kurulum.sh
   $ ./kurulum.sh
   ```
